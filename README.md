# Paynet — konsept super-ilova (React)

Mustaqil dizayn konsepti. Paynet bilan rasmiy aloqasi yo'q, barcha ma'lumotlar namunaviy.

## Ishga tushirish
```bash
npm install
npm run dev
```
Brauzerda http://localhost:5173 ni oching.

## Tuzilma
- `src/App.jsx` — asosiy qobiq, navigatsiya, umumiy holat
- `src/PayModal.jsx` — to'lov oqimi va chop etiladigan chek
- `src/pages/` — Bosh sahifa, Xizmatlar, Cheklar, Xarajatlar, Avtoto'lov, Terminallar, Profil, Admin
- `src/data.js` — provayderlar, terminallar, namunaviy tarix
- `src/ui.jsx`, `src/styles.css` — komponentlar va dizayn tokenlari

Stack: React 18, Vite, Tailwind CSS v4, framer-motion, recharts, lucide-react, sonner.
